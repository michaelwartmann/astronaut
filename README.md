# Mission Licht

Ein Astronaut aus Gemüse für Alinas 34. Geburtstag: die ganze Geschichte als kleine Website.

## Online stellen mit GitHub Pages

1. Auf GitHub ein neues Repository anlegen, z. B. `mission-licht`.
2. Den Inhalt dieses Ordners hochladen (Add file → Upload files): `index.html`, `README.md` und die Ordner `bilder` und `downloads`.
3. Im Repository: Settings → Pages → unter „Branch“ `main` und `/ (root)` wählen → Save.
4. Nach ein bis zwei Minuten ist die Seite erreichbar unter `https://DEIN-NAME.github.io/mission-licht/`.

## Die drei Fotos der Übergabe einfügen

Die Seite hat drei Platzhalter. Sobald ein Foto mit genau diesem Namen im Ordner `bilder` liegt, erscheint es automatisch:

| Dateiname | Motiv |
| --- | --- |
| `bilder/uebergabe-1.jpg` | Kerze aus, das Herz leuchtet weiter |
| `bilder/uebergabe-2.jpg` | Helm ab, die Mission wird entdeckt |
| `bilder/uebergabe-3.jpg` | Alina mit Astronaut, oder schon mit Suppe |

Am besten im Hochformat (3:4) und nicht größer als etwa 1600 Pixel, dann lädt die Seite schnell.

## Inhalt

- `index.html` – die komplette Seite (eine Datei, kein Build nötig)
- `bilder/` – Fotos vom Bau und die Ausmalbilder
- `downloads/` – die drei Ausmalbilder als druckfertige PDFs
